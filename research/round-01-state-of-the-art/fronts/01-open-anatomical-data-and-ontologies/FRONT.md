### 1. Open Anatomical Data & Ontologies

| Item | What it gives us | License verdict for AGPL use | URL |
|---|---|---|---|
| **Foundational Model of Anatomy (FMA)** — Univ. of Washington | Canonical human anatomy ontology: >81,000 classes, >120,000 terms, 139+ relationship types; the ID system BodyParts3D labels map to | **Usable with care.** The OWL release is cited as CC BY 3.0 in the literature; distribution via UMLS carries UMLS terms instead. Take the direct OWL download, keep attribution, do not take the UMLS copy if you cannot accept UMLS terms | https://pmc.ncbi.nlm.nih.gov/articles/PMC3944952/ |
| **Terminologia Anatomica 2 (TA2, FIPAT 2019, adopted 2020)** | Official Latin/English anatomical nomenclature, hierarchical IDs | **Terms: YES. Book: NO-derivatives.** Publication is CC BY-ND 4.0, but the text explicitly states *“the individual terms in this terminology are within the public domain”* and unaltered PDFs may be freely copied. Use the terms/IDs; do not publish a modified TA2 edition | https://libraries.dal.ca/find-resources/subject-guides/terminologia-anatomica.html (Dal­housie FIPAT library page as returned: https://cdn.dal.ca/content/dam/dalhousie/pdf/library/FIPAT/TA2/FIPAT-TA2-Part-5.pdf) |
| **BodyParts3D / Anatomography** — DBCLS, Japan | Full-body polygon atlas derived from a real adult male; every part keyed to an FMA ID. A downstream mirror counts **2,234 individual OBJ meshes** in the source | **YES — best primary geometry source, with a version trap.** DBCLS's current licence page (updated 2025-02-27) states **CC BY 4.0**. Legacy OBJ headers and older mirrors still say **CC BY-SA 2.1 Japan**. Pin the current DBCLS release, archive the licence page, attribute “BodyParts3D, © The Database Center for Life Science, CC BY 4.0”. Even under the old SA reading, AGPL distribution of the *data* is workable if the meshes stay CC BY-SA — but do not rely on the old reading | https://dbarchive.biosciencedbc.jp/en/bodyparts3d/lic.html (as cited at https://github.com/enruben/human-atlas/blob/HEAD/public/ATTRIBUTION.md) |
| **Z-Anatomy** | Community Blender atlas built on BodyParts3D: completed bilateral skeleton/muscles, ligaments, fasciae, lymphatics, brain nuclei, Latin names + definitions | **YES for most, NO for parts.** CC BY-SA 4.0 overall, **but its own licence file lists some models under CC BY-NC / BY-NC-SA (kidneys, inner ear in the cited audit)**. Per-object filtering is mandatory; a blanket import imports a non-commercial trap into an AGPL product | https://github.com/Z-Anatomy/Models-of-human-anatomy (audit summary: https://twin.aurasense.ai/anatomy-licences.md) |
| **NLM Visible Human Project (VHP)** — male & female | Cryosection + CT + MR of two cadavers. Male: 1,871 slices at 1 mm (~15 GB). Female: >5,000 slices at 0.33 mm (~40 GB) | **Usable, attribution required, not a public-domain dedication.** Since July 2019 *no licence agreement / registration is required*; NLM Terms & Conditions apply and require acknowledgement of NLM. Derived segmentations you make are yours, but the raw data is not CC-licensed — keep the NLM acknowledgement with any redistribution and do not claim CC status for it | https://www.nlm.nih.gov/research/visible/getting_data.html |
| **Open Anatomy Project / Open Anatomy Browser (OABrowser)** — SPL, Brigham & Women's / Harvard | Web atlas viewer (3D + labelled cross-sections + hierarchy) and published atlases incl. SPL/NAC Brain Atlas (MRI-derived, 2017) and SPL Abdominal CT Atlas (CT + label maps + 3D models) | **Viewer: YES. Atlases: under the 3D Slicer licence.** OABrowser source/data/tools are on GitHub “under a liberal open source licence”; SPL atlases state “License: 3D Slicer License section B” (BSD-style, acknowledgement in publications). Learn the atlas-interchange design even if you write your own viewer | https://nac.spl.harvard.edu/publications/open-anatomy-browser-collaborative-web-based-viewer-interoperable-anatomy-atlases ; https://www.openanatomy.org/atlas-pages/atlas-spl-nac-brain.html ; https://nac.spl.harvard.edu/publications/ct-based-atlas-abdomen |
| **TA2Viewer** — Open Anatomy Project / FIPAT | Live web browser for the TA2 hierarchy | **Code MIT; data = TA2 position above** | https://mhalle.github.io/taviewer/ |
| **Uberon** — OBO Foundry | Cross-species anatomy ontology, >6,500 classes at publication (grown since), species-neutral structures with xrefs to FMA etc. | **YES.** CC BY (OBO Foundry policy / paper is CC BY). Use as the bridge ontology, not the primary human label set | https://pmc.ncbi.nlm.nih.gov/articles/PMC3334586/ |
| **NIH 3D (formerly NIH 3D Print Exchange)** | Repository of biomedical 3D models (anatomy, molecules, labware) in STL/X3D/glTF etc., with per-model licence + DOI citation; QuickSubmit pipelines from PDB/AlphaFold/PubChem/EMDB | **Per-model only.** Platform FAQ/terms stress submission-time licensing/citation and de-identification; there is **no single blanket licence** covering every model. Harvest model-by-model, recording each model's stated licence; never bulk-scrape and assume public domain | https://3d.nih.gov/faqs ; https://3d.nih.gov/terms |
| **TotalSegmentator dataset + tool** — Wasserthal et al., Basel | nnU-Net segmenting **104 structures** in CT (v1 paper); dataset of **1,204 CTs**; MRI extension: 50 structures / 616 MRIs | **YES — cleanest imaging-derived source.** **Code Apache-2.0; dataset CC BY 4.0.** Note: some *pretrained subtask weights* distributed with the tool have carried separate non-commercial terms historically — use the main `total` task and check the current licence file per weight set before shipping weights | https://github.com/wasserth/TotalSegmentator (dataset licence as cited: https://www.corpxanalytics.com/methods/) |
| **CT-ORG, Medical Segmentation Decathlon (MSD), SAROS, AbdomenAtlas** | Labeled CT corpora: CT-ORG (organs-at-risk labels on TCIA CTs), MSD (10 tasks, multi-organ), SAROS (body-composition segmentations on TCIA), AbdomenAtlas (large-scale annotated abdominal CT, ~20+ structures) | **Mixed — verify per dataset before any use (see Could not verify).** These are research datasets, typically CC BY-SA / CC BY-NC-SA or TCIA data-use terms, *not* uniformly redistributable. Treat as **validation data you download at runtime / in CI**, not as assets you bundle, until each licence is pinned. MSD in particular has historically been CC BY-SA 4.0; TCIA-hosted sets inherit TCIA terms | (no single canonical URL verified in this pass — see Could not verify) |
| **Human Reference Atlas (HuBMAP HRA)** | 3D reference organs placed in a reference body, ASCT+B tables linking anatomy ↔ cell types ↔ biomarkers | **YES.** CC BY 4.0 per-organ metadata (as audited in downstream licence files). Good complement for organ placement / cell-type annotation; does **not** cover full skeleton/musculature | https://twin.aurasense.ai/anatomy-licences.md (audit citing HRA records) |

**Design consequence:** build the “one verified body model” as a *provenance-tracked composite*: BodyParts3D geometry (CC BY 4.0) + TotalSegmentator-derived labels/meshes for imaging consistency (CC BY 4.0) + selective Z-Anatomy fills (CC BY-SA, NC parts excluded) + FMA/TA2 IDs as the naming spine. Every mesh carries source, licence, and version in its metadata — this is also what Front 11 requires.
